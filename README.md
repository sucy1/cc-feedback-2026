# cc-feedback-2026

CC/Codex 用户反馈标注（领域专项）题目底座与产物快照仓库。

## 目录约定

每道题一个独立目录，命名 `<领域前缀>-<项目名>-<序号>`：

```
sec-titus-001/     # 安全
gfx-gpujs-001/     # 图形与多媒体
data-pandas-001/   # 数据工程
```

## 目录内约定

- 代码为底座项目在某个固定 commit 上的快照，**不含上游 git 历史**，每个目录只有本仓库产生的提交。
- 每个目录带 `SOURCE.txt`，记录上游仓库、冻结 commit、许可证与导入日期。
- `LICENSE` / `NOTICE` 等许可证文件原样保留，不删除。
- 题面、参考材料、产物一并提交在该目录内；改动请另起提交，不做 squash、不改写历史。

## 提交规范

- 初始快照在首轮执行前提交一次，产物快照在跑完后提交，两者都是 40 位完整 SHA 的 commit permalink。
- 初始快照必须是产物快照的祖先提交，禁止 force-push 与 rebase。
